ABOUT

About YouScraper

YouScraper is a local utility for extracting and organizing public YouTube metadata from channels and playlists, then exporting it into useful formats.

FAQ

Does YouScraper download YouTube videos?

No. YouScraper extracts public metadata only. It does not download the actual video files.

Does it require a YouTube API key?

No. The application uses the bundled yt-dlp extraction engine rather than the YouTube Data API.

Does it require Python to be installed?

No for the released desktop application. The packaged release bundles the runtime and required dependencies.

Can it handle YouTube Shorts?

Yes, wherever Shorts are publicly exposed through the channel or playlist extraction path used by yt-dlp.

Can it extract playlist information?

Yes. Playlist Organizer discovers public playlists and keeps playlist identity and original sequence with the extracted records.

Can I export the results?

Yes. Results can be exported as UTF-8 TXT, Excel-friendly CSV, or landscape selectable-text PDF.
